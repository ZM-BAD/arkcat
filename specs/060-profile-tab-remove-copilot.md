## 一、页面/功能概述

> 本批改应用外壳（底栏 + Home 头部），不改三个内容 Tab 的页内实现。

底栏由「四 Tab（Home / Inbox / Explore / Copilot）」变为「Home / Inbox / Explore / 我的主页」四 Tab：
前三个内容 Tab 不变，**tab4 是当前账号的个人主页**——它的图标就是当前账号头像，与三 Tab 共用同一套
胶囊选中态（选中时浅蓝胶囊底 + 蓝色标签）。tab4 是**真 Tab**（切内容、清二级页栈），不是跳转按钮；
他人个人主页仍走 `userProfile` 压栈路由，两者语义分开：底栏进「我的」，列表进「他的」。
同时移除 Home 头部右上角的头像（入口从「头部右上角」迁到「底栏 tab4」，两处不并存）。Copilot 的页面、
服务、模型、本地会话存储、i18n 文案与图标资源一并移除。

## 二、整体 UI 结构

1. 底部常驻自绘栏（官方浮层样式）：Home / Inbox / Explore / 我的主页 四个 Tab
   - 前三个为既有结构（图标 + 文字标签；选中态浅蓝胶囊底 + fill 图标变体），不变
   - tab4「我的主页」：图标为当前账号圆形头像（20vp，与兄弟图标同尺寸）+ 文字标签「Me」；
     选中态与三 Tab 完全一致（56×32 浅蓝胶囊底 + 蓝色标签）
   - 头像加载中或拉取失败：底色占位圆（同 Home 用户卡片头像的兜底做法）
2. Home 头部：`Home` 标题 + 搜索 / 刷新 / 新建 三个操作（**移除原第四个操作「头像」**）
   - 三操作随头像移除整体右移，最右为新建（＋）
3. 应用内浏览器页（`inAppBrowser`）、Settings 页：本批不改版面

## 五、边界 / 不可行项

| 项 | 原因 | ArkCat 处理方式 |
| ---------------------- | ------------------------------------------------- | ------------------------------------------------------------ |
| 头像异步加载 | 底栏常驻，头像为网络资源 | 未拉到 / 失败时显示底色占位圆，不显示破图 |
| 头像在 Tab 图标位的可辨识度 | 图标位仅 20vp（与前三个 Tab 的图标同尺寸） | 尺寸优先对齐兄弟图标；本账号 Profile 内的头像大图与账号切换器（长按）不受影响 |
| 我的主页无返回钮 | tab4 是根页，无上级页可返回 | `showBack=false`（Profile 新增参数）；他人主页（压栈）仍显示返回钮 |
| 官方底栏无头像项 | 官方当前结构为 3 Tab + 屏幕角落头像（Community Discussion #207516） | 有意识地偏离官方：头像入底栏 tab4（用户定案），记入第七章 |
| 应用内浏览器失去唯一入口 | 其唯一调用方 `CopilotSettings` 随本批移除，页面暂不可达 | 本批保留页面与路由（Spec 014 的 Terms/Privacy/Open Source 行后续接入），不删 |

## 七、备注

- **状态说明**：实现已完成并通过构建与全部门禁；第六章测试 5-11 为模拟器/设备实测项，走查通过后置
  `implemented`。
- **tab4 语义**：真 Tab（选中态源 `currentTab === 3`），点击清二级页栈并切内容——与 Home/Inbox/Explore
  同规则；他人主页不受影响（仍走 `userProfile` 压栈路由，保留返回钮）。
- **重取时机**：tab4 是常驻根页（TabContent 不清毁），故 Index 泵 `refreshTick`——① 切到 tab4（`Tabs.onChange`
  index=3）② 从二级页返回根页且当前停在 tab4；Profile 收到 tick 后走**静默重取**（保留当前内容、不回退
  loading、失败不接管页面），避免每次切 Tab 闪一次骨架。
- **viewer 单一请求**：全应用只发一次 `viewer` 查询（HomeView 的连通性探针，兼作底栏降级提示），头像经
  `onViewer` 回调上报给 Index；切号时 Index 先清空头像再等回填。
- **竞态防护**：Home 与 Profile 都以「请求代际 / 令牌快照」丢弃旧账号的响应；Profile 在切号时先清掉上一个
  身份的 `profile/achievements/orgCount/menu`，避免常驻根页显示上一个账号的数据。
- **还原度原则（用户 2026-09-11 定调）**：设计标准由「体验级复刻」调整为**「合规优先的体验级复刻」**
  ——满足中国法律法规与上架合规要求（备案、内容与生成式 AI 合规、网络可达性）是前提，其余**最大程度
  还原**官方；无合规理由的偏离应避免。本批 Copilot 移除属合规必需；tab4 头像入口属官方暂无的增强
  （用户拍板），不是为省事而偏离。
- **与官方 App 的差异**：官方底栏当前为 Home / Notifications / Explore + 头像在屏幕角落（关闭 Copilot
  后仅 3 个按钮）；ArkCat 把头像放进底栏 tab4 属有意识改进，不是复刻。项目「体验级复刻」标准中，底栏
  项构成属信息架构层，此处偏离已由用户 2026-09-11 拍板认账。
- **移除而非隐藏入口**：Copilot 的代码与资源整体删除，符合「死代码与死资源清理」口径；若将来需要海外
  版本，可从 git 历史恢复（本批在独立分支完成）。
- **唯一的有意保留项**：`inAppBrowser` 页面与路由保留，但本批后**暂不可达**（唯一入口 CopilotSettings 已
  移除）——为 Spec 014 的 Terms / Privacy / Open Source 三条 coming-soon 行预留；接入后即恢复可达，
  若确定不接入应删除页面、路由与 `TAB_BAR_HIDDEN_ROUTES` 中的 `inAppBrowser` 项。
- **隐私政策同步**：`docs/privacy-policy.md` 中 `api.githubcopilot.com` 出口、本地 Copilot 用量记账等
  表述随功能移除一并删除；AGC「协议服务」托管的隐私政策需用户侧同步更新。
- **备案侧无影响**：工信部 App 备案的 App 名称 / 内容分类 / 语言 / 接入信息均不变，本批不触发变更备案。
