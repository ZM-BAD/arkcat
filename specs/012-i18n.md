# Spec 012: 国际化 i18n（英语 / 简体中文，默认英语）

> BFS Level: 4（全局横切）
> 关联截图: 无（资源层改动，不影响 UI 布局）
> 上游 Spec: 001-007（所有页面的字符串统一收口）
> 状态: implemented（2026-08-31，资源拆分 + 全量替换完成）

---

## 一、页面/功能概述

StarRaft 目前所有用户可见文案均为中文硬编码（部分在 `resources/base/element/string.json`，大量仍散落在 pages/components/utils/services 中）。

本 Spec 为全应用增加国际化能力：

- 支持语言：英语（默认）、简体中文
- 语言判定：跟随系统语言；系统语言为简体中文时使用 `zh_CN` 资源，其他语言一律回退到 `base`（英文）
- 实现方式：HarmonyOS 资源限定词目录（`base` = 英文，`zh_CN` = 简体中文），UI 通过 `$r('app.string.*')` / `resourceManager.getStringSync` 引用
- 范围：全部用户可见字符串（页面、组件、Toast、Empty State、格式化文案）；服务层技术性错误消息改为英文基线（GitHub API 错误本身是英文）

## 二、整体 UI 结构

语言资源组织（不改变 UI 布局，仅替换文案来源）：

```text
entry/src/main/resources/
├── base/element/string.json        # 默认（英文）— 非中文系统一律回退到这里
└── zh_CN/element/string.json       # 简体中文

字符串引用路径（组件内）：
  $r('app.string.xxx')                                    静态文案
  getContext(this).resourceManager.getStringSync(
      $r('app.string.xxx').id, args...)                  带参格式化
```

## 四、核心接口（资源映射）

无 GraphQL 新增。资源访问接口：

```typescript
// 1. 静态文案：Resource 直接给 Text
Text($r('app.string.issues_empty'))

// 2. 带参格式化（getStringSync API 10+，参数用 %1$d / %1$s 位置占位）
const rm = getContext(this).resourceManager;
const text = rm.getStringSync($r('app.string.time_minutes_ago').id, 5);
// string.json: { "name": "time_minutes_ago", "value": "%1$d minutes ago" }  (base)
//            { "name": "time_minutes_ago", "value": "%1$d 分钟前" }          (zh_CN)

// 3. 纯函数只产出结构化数据，文案翻译收敛在 UI 层
//    timeParts(iso, nowMs) → { value: 5, unit: 'minute' } | null
```

## 五、边界 / 不可行项

| 项 | 原因 | StarRaft 处理方式 |
| ---- | ------ | ------------------- |
| 应用内手动切换语言（设置页） | 无设置页 Spec，且 `setAppPreferredLanguage` 仅冷启动生效 | 本次不做，跟随系统语言；如需手动切换留待 Settings Spec |
| GitHub API 返回文案（通知 reason/issue 标题/language 名） | 第三方数据，非我方文案 | 原样展示，不翻译 |
| Log/hilog 输出 | 开发者可见 | 保持中文注释与英文 TAG 现状 |
| 繁体中文 / 多地区变体 | 超出需求范围 | 不支持，回退英文 |

## 七、备注

- 语言资源遵循 HarmonyOS 限定词目录规范：`base` 匹配一切语言及回退，`zh_CN` 匹配简体中文系统（见 资源分类与访问.md）——「默认英语」即 base 装英文。
- 格式化字符串统一使用位置占位符 `%1$d` / `%1$s`（`getStringSync` 示例为位置参数），旧文件中 `%d` 占位的 `repo_stars_fmt` 等一并迁移。
- 组件 `StateView.emptyText` 参数类型由 `string` 放宽为 `Resource`（Text 原生支持 ResourceStr），调用方直接传 `$r(...)`。
- 测试仍运行于 ohosTest（模拟器 aa test），纯函数部分不依赖 ResourceManager，保持可单测。
